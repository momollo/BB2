🔗 MODÈLES ET RELATIONS
═══════════════════════════════════════════════════════════════════════════════

User Model                          Recette Model
├── id (PK)                         ├── id (PK)
├── name                            ├── title
├── email (UNIQUE)                  ├── body
├── password                        ├── user_id (FK) → users.id
├── remember_token                  ├── created_at
├── email_verified_at               └── updated_at
├── created_at
└── updated_at

Relations:
  • User HasMany Recette (1:N)
  • Recette BelongsTo User (N:1)

═══════════════════════════════════════════════════════════════════════════════
🎮 ROUTES ET CONTRÔLEUR (CRUD)
═══════════════════════════════════════════════════════════════════════════════

GET    /recettes                → RecetteController@index()       [Lister]
GET    /recettes/create         → RecetteController@create()      [Formulaire]
POST   /recettes                → RecetteController@store()       [Sauvegarder]
GET    /recettes/{id}           → RecetteController@show()        [Afficher]
GET    /recettes/{id}/edit      → RecetteController@edit()        [Formulaire]
PUT    /recettes/{id}           → RecetteController@update()      [Mettre à jour]
DELETE /recettes/{id}           → RecetteController@destroy()     [Supprimer]

Génération automatique par: Route::resource('recettes', RecetteController::class)

═══════════════════════════════════════════════════════════════════════════════
✅ MÉTHODES DU CONTRÔLEUR
═══════════════════════════════════════════════════════════════════════════════

index()
├─ Récupère: Recette::all()
├─ Requête: SELECT * FROM recettes
└─ Affiche: Vue avec liste des recettes

create()
├─ Affiche: Formulaire vide
└─ Vue: recette/create.blade.php

store(Request $request)
├─ Valide: title (required), body (required)
├─ Crée: Recette::create($validated)
├─ Insère: INSERT INTO recettes
└─ Redirige: /recettes avec succès

show(Recette $recette)
├─ Model Binding résout {id}
├─ Affiche: Vue détails de la recette
└─ Vue: recette/show.blade.php

edit(Recette $recette)
├─ Model Binding résout {id}
├─ Affiche: Formulaire pré-rempli
└─ Vue: recette/edit.blade.php

update(Request $request, Recette $recette)
├─ Valide: title (required), body (required)
├─ Met à jour: $recette->update($validated)
├─ Requête: UPDATE recettes SET ... WHERE id=?
└─ Redirige: /recettes avec succès

destroy(Recette $recette)
├─ Supprime: $recette->delete()
├─ Requête: DELETE FROM recettes WHERE id=?
└─ Redirige: /recettes avec succès

═══════════════════════════════════════════════════════════════════════════════
🔒 MIDDLEWARE STACK
═══════════════════════════════════════════════════════════════════════════════

Chaque requête passe par:

1. EncryptCookies           - Chiffre les cookies
2. AddQueuedCookiesToResponse - Ajoute cookies en attente
3. StartSession             - Démarre la session
4. ShareErrorsFromSession   - Partage erreurs avec vues
5. VerifyCsrfToken          - Vérifie token CSRF (POST/PUT/DELETE)
6. SubstituteBindings       - Résout Model Binding ({id})
7. Authorize               - Vérifie autorisations (if any)

═══════════════════════════════════════════════════════════════════════════════
📝 VUE D'ENSEMBLE - FLUX CRÉATION
═══════════════════════════════════════════════════════════════════════════════

1. Utilisateur clique "Créer une recette"
   → GET /recettes/create

2. Navigateur charge le formulaire
   ← index.blade.php (formulaire vide)

3. Utilisateur remplit titre et description
   → POST /recettes (avec CSRF token et données)

4. Validation des données
   ✓ Valide   → Recette::create() → INSERT → Succès
   ✗ Invalide → Retour au formulaire avec erreurs

5. Redirection vers la liste
   → GET /recettes

6. Affichage de la liste actualisée
   ← index.blade.php (avec la nouvelle recette)

💡 POINTS CLÉS DE L'ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

✓ Model Binding
  → Laravel résout automatiquement {id} en objet Recette

✓ Validation Centralisée
  → Dans le contrôleur avec $request->validate()

✓ Protection Mass Assignment
  → Attribut $fillable définit les colonnes modifiables

✓ Eloquent ORM
  → Abstraction de la base de données

✓ Middleware CSRF
  → Protège contre les attaques cross-site

✓ Timestamps Automatiques
  → created_at et updated_at gérés par Laravel

✓ Factory Support
  → Tests et seeders avec RecetteFactory
