🔄 FLUX D'EXÉCUTION - EXEMPLE: CRÉATION DE RECETTE
═══════════════════════════════════════════════════════════════════════════════

1. USER ACTION
   User clicks "Create Recette"

2. HTTP REQUEST
   GET /recettes/create

3. ROUTING
   Router matches to RecetteController@create

4. MIDDLEWARE PIPELINE
   ├─ EncryptCookies
   ├─ AddQueuedCookiesToResponse
   ├─ StartSession
   ├─ ShareErrorsFromSession
   ├─ VerifyCsrfToken
   ├─ SubstituteBindings
   └─ Authorize (if any)

5. CONTROLLER ACTION
   RecetteController::create()
   └─ return view('recette.create')

6. VIEW RENDERING
   Blade template recette/create.blade.php
   └─ Generates HTML form with CSRF token

7. HTTP RESPONSE
   Returns form HTML to browser

8. USER FILLS FORM & SUBMITS

9. NEW HTTP REQUEST
   POST /recettes
   Form data + CSRF token

10. VALIDATION
    $request->validate([
        'title' => 'required',
        'body' => 'required'
    ])

11. SUCCESS PATH
    ├─ Recette::create($validated_data)
    ├─ INSERT INTO recettes
    ├─ Database returns new record
    ├─ Session flash success message
    └─ Redirect to /recettes (index)

12. OR FAILURE PATH
    ├─ Validation errors collected
    ├─ Errors stored in session
    ├─ Redirect to /recettes/create
    └─ Form displayed with error messages

13. FINAL RESPONSE
    ├─ View rendered with data
    ├─ HTML sent to browser
    └─ User sees result
